# SportsmeetsAI
Sports meets AI – Gamification, Personalized Learning  

#Project Objectives
This project aims to build an AI-powered taekwondo training and scoring system. By uploading instructor videos (or referencing YouTube forms) and student practice videos, the system will detect poses, compare movement sequences, grade performance, and offer actionable feedback. The goal is to democratize martial arts training with real-time, explainable AI guidance. Well this is just the tip of the iceberg, the same can be extended for an array of Sports/ team based events etc and potentially be embedded with some sort of edge device to address latency /a Virtual reality and Robotics too
